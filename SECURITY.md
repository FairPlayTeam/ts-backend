# Security Policy

FairPlay is still a small niche project, but security reports are welcome.

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive reports.

If you find a vulnerability, please contact us at `contact@fairplay.video` with:

- a short description of the issue
- steps to reproduce it
- the affected route, feature, or dependency
- any suggested fix, if you already have one

We will acknowledge the report as soon as possible.

## Supported Versions

Only the current v2 codebase is actively maintained.

## Scope

Useful reports include authentication bypasses, token/session handling issues, data exposure, injection bugs, unsafe defaults, dependency vulnerabilities, and production configuration risks.
